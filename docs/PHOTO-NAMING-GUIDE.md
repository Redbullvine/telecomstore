# Telecom Store Photo Naming Guide

Use this pattern so BAINTU can connect photos to products automatically.

## Folder

Put product photos here:

`public/images/products/`

## File names

Use SKU-first names:

- `80-6110-4831-7-main.jpg`
- `80-6110-4831-7-label.jpg`
- `80-6110-4831-7-side.jpg`
- `4005GPM-TR-main.jpg`
- `4005GPM-TR-label.jpg`

## Best photo set for each product

1. Full box or pallet photo.
2. Close-up label photo showing SKU, brand, count, and barcode.
3. Open-box photo if it helps verify material type.
4. Quantity/count photo if there are multiple cases.

## Do not publish until verified

Before a product goes live, verify:

- SKU
- Brand
- Quantity available
- New / used / open box status
- Case count or pieces per box
- Any job-specific compatibility notes
